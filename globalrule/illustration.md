# Illustration

## Principle
* イラストは、コンテンツの内容をより明快に、直感的な理解を促す目的で利用します
* 不快感、誤解を与えるイラスト表現は禁止とします

## Usage
イラストは最大限効果的な方法で使用します。

### 直感的に伝える
テキストのみではなくイラストを利用することで、コンテンツの内容をより深く伝えることができます。
また、キャンペーンなどの演出に装飾要素として利用することで、ユーザーの気持ちを盛り上げ心を動かすことができます。

カテゴリーを視覚的に説明することでユーザーの理解をサポートする
![カテゴリーを表すイラスト](https://developer.paypay.ne.jp/static/img/Illustration_usage_01.860fc162.svg)
当選情報の伝達とともに、装飾による演出でユーザーの気持ちを盛り上げる
![キャンペーンの装飾イラスト](https://developer.paypay.ne.jp/static/img/Illustration_usage_02.e04534d3.svg)

### 直感的に伝える
説明図などのイラストでは、簡略化したシンプルなイラストを用い、ユーザーがイラストからすぐに情報を読み取れるようにします。

文字だけでは説明しきれない部分をイラストでサポート
![サービスの利用手順の説明](https://developer.paypay.ne.jp/static/img/Illustration_usage_03.adebae68.svg)

### 表現
![イラスト表現](https://developer.paypay.ne.jp/static/img/Illustration_usage_04.b84219b8.svg)

イラスト表現に用いるモチーフは極力簡略化しシンプルに構成する
カラーは塗り表現のみを用い、[Color](./color.md)項目のカラーパレットの色を参考に構成する
無機質すぎない親しみやすい表現を用いる
指定がない場合は個人や特定の企業が判別できるような表現はしない

![番号付きのイラスト](https://developer.paypay.ne.jp/static/img/Illustration_usage_05.791fe717.svg)

| 番号 | 名称 | 説明 |
| :--- | :--- | :--- |
| 1 | Focal Point | より強調したい部分、主題を表現している部分により強い色を使用します。対して補助的な部分にはトーンの低い色を使用し、イラストにメリハリをつけ主題を明確にします。 |
| 2 | Facial Expression | 人物を使用する場合は、必要な場合を除き、原則表情、目などの顔の部品を描かないようにします。 |
