# Shape

## Principle
* Componentを構成する形状は、必ず一般的な形状を用い、表示される情報の可読性を阻害するような形状の利用は禁止とします。
* ガイドラインに沿った形状を繰り返し利用することで一貫性を保ち、PayPayブランドを醸成します。

## Usage
コンポーネントの角は丸くし、肌触りの良さ、親しみやすさを表現します。

![](https://developer.paypay.ne.jp/static/img/shape_01.aec04f26.svg)

## Spec
角丸は 8px / 20px に統一します。

![角の丸みをマークアップした画像](https://developer.paypay.ne.jp/static/img/shape_02.250777f0.svg)

Card, Buttonなど : 8px/dp
Half Sheets : 20px/dp
